
# Frecool
### VS Code + Next.js that runs on Android - no laptop needed.
**Built in Nigeria on phone only 🇳🇬**

> From 31 tabs at 3AM in Calabar to a working dev environment on Android.

### 🚀 What is Frecool?
Offline IDE to build real Next.js apps directly on your Android phone. No laptop, no data needed after install.

- Code: Monaco Editor (same as VS Code)
- Preview: Live Next.js runtime
- Offline: Works 100% without internet
- Phone-First: Built for small screens, low RAM

### The Problem
10M young Africans have Android phones but no laptops. Learning to code requires a laptop they can't afford. Frecool removes that barrier.

### How it works
1. Open Frecool on Android
2. Create new project
3. Code in /app/page.tsx
4. Tap Preview - see Next.js app running instantly
5. Export / Publish

### Tech Stack
- React Native + Expo
- Monaco Editor
- Next.js WebView Runtime
